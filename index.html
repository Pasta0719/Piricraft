PiriCraft

Private / Closed Project

PiriCraft is a private custom launcher for a closed Minecraft Java Edition multiplayer project. It is not publicly distributed.

The launcher is designed to use Microsoft's official authentication flow and Minecraft Services APIs so that users authenticate with their own Microsoft account and use their legitimate Minecraft Java Edition profile.

Purpose

  • Authenticate users through Microsoft's official sign-in flow.
  • Obtain the authenticated user's Minecraft profile through Minecraft Services.
  • Launch the configured Minecraft Java Edition client for the private project.

Security and licensing

PiriCraft does not bypass Microsoft authentication, Minecraft ownership or license checks, or Minecraft security mechanisms.
